이 세 출처는 배포 후 같은 조건의 느린 쿼리와 연결 대기가 관측됐다는 시간 순서를 지지한다. 이 사건의 인덱스 상태, 실행계획 변경, 개별 쿼리의 연결 점유 시간은 해당 원문에서 확인할 수 없다. 비인덱스 컬럼이나 전체 스캔을 확정하려면 해당 스키마와 변경 전후 EXPLAIN 등 독립적인 자료가 필요하다. 과거 보고서의 실행계획은 당일 쿼리의 실행계획을 대체할 수 없다.

실행 후에는 모델이 실제로 사용한 각 인용의 ID·버전·파일·행·텍스트를 같은 시드의 원문과 대조한다. 위 세 관찰을 얼마나 다뤘는지, 어느 지점에서 인과를 유보하거나 과도하게 확정했는지 모델 출력 그대로 평가한다. 누락된 인용을 사후에 보충하지 않는다. 검색기의 Redis 사례 제외 여부는 해당 검색의 결정 기록에서 읽고, 모델이 직접 언급한 대안 판단은 제출한 보고서에서 따로 확인한다.
