# 장애 보고서: 롤백 실패로 장애 연장 (2024-05-23)

## 요약
2024-05-23 15:10 ~ 16:44 동안 사용자 프로필 API 오류가 지속되었다. 최초 원인은
배포된 코드의 NPE였으나, 롤백 대상 이전 버전 이미지가 레지스트리 정리 정책으로
삭제되어 있어 롤백이 실패했고 장애가 60분 이상 연장되었다.

## 근본 원인
직접 원인은 신규 코드의 널 처리 누락(NPE)이다. 그러나 장애를 연장시킨 구조적
원인은 이미지 레지스트리 보존 정책(최근 3개)이 롤백 요구사항과 충돌해,
롤백 가능 버전이 존재하지 않았던 것이다.

## 5 Whys
1. 왜 프로필 API가 실패했나? — 신규 코드에서 NullPointerException이 발생했다.
2. 왜 즉시 복구하지 못했나? — 이전 버전으로의 롤백이 실패했다.
3. 왜 롤백이 실패했나? — 이전 버전 이미지가 레지스트리에 없었다.
4. 왜 이미지가 없었나? — 보존 정책(최근 3개)이 핫픽스 연속 배포로 이전 안정 버전을 밀어냈다.
5. 왜 정책 충돌을 몰랐나? — 롤백 훈련이 스테이징에서만 수행되어 프로덕션 정책과 달랐다.

## 재발 방지 대책
- [완료] 마지막 안정(stable) 태그 이미지는 보존 정책에서 제외
- [완료] 배포 파이프라인에 롤백 대상 이미지 존재 사전 검증 추가
- [진행] 분기 1회 프로덕션 롤백 훈련 정례화
